# 川崎沼田クリニック TOPページ（川崎沼田デザイン004）

ゼロからデザインし、そのままコーディングしたTOPページです。HTML・CSS・JavaScriptだけで動く静的サイトです。

## ファイル構成
- index.html … ページ本体
- assets/css/style.css … デザイン（色・書体は先頭の変数で一括管理）
- assets/js/main.js … D文字（デザイナーズ文字詰め）、スマホメニュー、ブログバナーを閉じる、TOPボタン、受診の目安のふきだし表示
- assets/img/ … 院長写真（仮のサンプル）、ロゴ

## デザインの考え方
- コンセプトは「会話」。キャッチ「こころ、こんにちは。」に合わせて、ふきだし・アーチ・縦書きを共通の形にしています
- 書体：M PLUS Rounded 1c（400／500）、英字は Varela Round（Google Fonts）
- 色：文字はすべて夜藤 #463A6B、強調はロゴの紫 #AB589D、差し色に空色 #8CCBEA とクリーム #FFE58A

## D文字について
見出し・ボタン・ラベルなど class="dmoji" の付いた文字は、main.js が1文字ずつ詰めます。
詰め量は M PLUS Rounded 1c（500）の字形を測って作った表です。文言を書き換えても自動で詰め直されます。
ボタンなど改行させたくない文字には dmoji-nw も付けています。

- 院長紹介・診療案内・お知らせ等のリンク先は、仮に既存サイトのTOPを指しています
